# Политика конфиденциальности DocsMasked Relay

Дата: 23.11.2026. Версия расширения: 0.2.0.

Политика относится к расширению DocsMasked Relay для Chrome (Chrome Web Store) и
Microsoft Edge (Edge Add-ons), а также к Safari Web Extension, если она будет
распространяться отдельно. Версия для магазина: `store/privacy-policy.html`.

DocsMasked Relay — расширение браузера, которое локально находит персональные данные
(PII) в файлах перед отправкой в ChatGPT, заменяет их метками и восстанавливает при
скачивании. У расширения нет сервера, аккаунта, телеметрии, аналитики, рекламы и внешних
API. Разработчик не собирает и не получает пользовательские данные.

## 1. Какие данные обрабатываются

- Содержимое выбранных или перетащенных файлов, их имена и метаданные.
- Настройки расширения: включение перехвата, категории персональных данных, лимиты,
  списки терминов.
- Хранилище (vault): зашифрованное соответствие меток и исходных значений, а также имена
  файлов.
- Служебные идентификаторы: код хранилища (5 символов), id чата ChatGPT, время операций.

Обработка идёт в браузере, внутри расширения. Скрипт на странице ChatGPT только
перехватывает файл и передаёт его расширению; поиск данных, замена метками и работа с
форматами выполняются в фоновой части расширения. PDF обрабатывается там же (в Chrome/Edge —
с помощью отдельной служебной страницы браузера). Отдельного сервера нет.

**Минимум данных.** Расширение обрабатывает только те файлы, которые пользователь сам
выбирает или отправляет в ChatGPT, и только в объёме, необходимом для локальной замены
метками и восстановления. Оно не читает другие сайты, не строит профили, не собирает
историю просмотров и не использует данные для рекламы, аналитики или оценки
кредитоспособности. Содержимое файлов не передаётся разработчику и не попадает на
сторонние серверы, кроме описанной ниже отправки обезличенной копии в ChatGPT.

## 2. Что покидает устройство

Только то, что пользователь сам отправляет в ChatGPT:

- обезличенные файлы — в chatgpt.com и на подписанные URL `*.oaiusercontent.com`
  (инфраструктура OpenAI/Azure);
- обезличенное имя файла и служебные метаданные загрузки (размер, тип файла);
- запросы к chatgpt.com, которые создаёт сам веб-клиент ChatGPT;
- при скачивании — запросы к тем же доменам ChatGPT/OpenAI.

Хранилище, ключи шифрования, настройки и **исходные значения персональных данных не
отправляются** никому. В ChatGPT уходит только обезличенная копия; исходные значения
остаются на устройстве пользователя. Расширение не продаёт данные, не передаёт их третьим
лицам для их собственных целей и не использует для рекламы.

Важно: после отправки обезличенная копия файла хранится у OpenAI по политике OpenAI.
Расширение не защищает от самого ChatGPT и не отменяет правила сервиса.

## 3. Хранение, шифрование, сроки и удаление

- Хранилище и ключи хранятся в локальной базе браузера (IndexedDB расширения, `dmrelay`),
  а не в облаке.
- Содержимое хранилища шифруется алгоритмом AES-GCM-256. Ключ устройства хранится как
  неэкспортируемый `CryptoKey`; дополнительная парольная фраза защищает основной ключ
  через PBKDF2-SHA256 (600 000 итераций, соль 16 байт).
- Служебные метаданные хранилища (код хранилища, id чатов, время операций,
  IV/шифротекст) не содержат персональных данных; имена файлов и значения сущностей
  находятся только внутри шифротекста.
- **Исключение:** списки «Свои термины» (`customTerms`) и «Список исключений»
  (`allowlist`) в настройках хранятся в открытом виде и не входят в шифрованное
  хранилище. Если вы вписываете туда реальные имена или термины, они видны в локальной
  базе расширения без парольной фразы. Шифрование этих списков пока не реализовано.
- **Сроки хранения:** хранилище хранится до удаления пользователем; служебная запись о
  загрузке живёт 2 минуты после перехвата; автоблокировка по умолчанию срабатывает через
  15 минут бездействия и очищает ключ из памяти. Отдельного серверного хранения нет.
- Экспорт создаёт только зашифрованный JSON с отдельной парольной фразой. Импорт
  отклоняет дубликаты id и кодов хранилища.
- **Удаление:** «Настройки → Очистка данных» удаляет хранилище, ключи и настройки без
  возможности восстановления. Удаление расширения из браузера также удаляет его локальные
  данные. Запрашивать удаление у разработчика не нужно, потому что разработчик данные не
  получает.

## 4. Разрешения и зачем они нужны

| Разрешение                                                    | Назначение                                                                           |
| ------------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| `storage`                                                     | Настройки и служебные флаги.                                                         |
| `unlimitedStorage`                                            | Хранилище в IndexedDB.                                                               |
| `offscreen` (Chrome/Edge)                                     | Служебная страница браузера для обработки PDF; используется только при работе с PDF. |
| Доступ к `https://chatgpt.com/*`, `https://chat.openai.com/*` | Перехват загрузки и скачивания на страницах ChatGPT.                                 |
| Доступ к `https://*.oaiusercontent.com/*`                     | Передача и получение байтов по подписанным ссылкам.                                  |
| Скрипты на страницах                                          | Только на chatgpt.com, для перехвата файлов и связи со страницей.                    |

Расширение не запрашивает разрешения `tabs`, `downloads`, `debugger` или `<all_urls>` и не
загружает удалённый код.

## 5. Chrome Web Store / Google API Limited Use

**The use of information received from Google APIs will adhere to the Chrome Web Store
User Data Policy, including the Limited Use requirements.**

Расширение не использует Google API и не получает данные от Google. Тем не менее любая
обработка пользовательских данных ограничена заявленной единственной целью — локальная
замена персональных данных в файлах для ChatGPT метками и восстановление при скачивании.
Данные не используются и не передаются для рекламы, аналитики, профилирования, оценки
кредитоспособности или иных задач, не связанных с этой целью.

## 6. Microsoft Edge Add-ons

Настоящая политика применяется к расширению, распространяемому через Microsoft Edge
Add-ons. Расширение получает доступ к данным только в объёме, необходимом для явно
заявленной пользователю функции (локальная замена данных в файлах метками и
восстановление), и обрабатывает их локально. Разработчик не собирает, не продаёт и не
передаёт данные третьим лицам; аналитики, рекламы и удалённой конфигурации нет. Поскольку
данные не передаются разработчику или третьим лицам, отдельное согласие на такую передачу
не требуется; установка и явное включение перехвата — действия пользователя. Пользователь
может отключить перехват, очистить данные или удалить расширение в любой момент.
Требования Edge Add-ons к раскрытию и минимизации данных соблюдаются; политика
распространяется и на Edge-версию того же пакета.

## 7. Ограничения

- Расширение не является юридической консультацией и не гарантирует соответствие 152-ФЗ
  или иным требованиям.
- PDF после необратимого удаления (redaction) не восстанавливается — это удаление в одну
  сторону.
- Сканы PDF без текстового слоя блокируются; распознавание текста (OCR) не входит в эту
  версию.
- Изображения, встроенные объекты, диаграммы и вложения внутри документов не проверяются.
- Старые форматы (legacy) `.doc` и `.xls` конвертируются в `.docx` и `.xlsx` с потерей
  вёрстки.
- JSON: числовые значения с признаками персональных данных (ИНН/СНИЛС/ОГРН/карта/счёт/
  телефон) отклоняются, а не заменяются метками; построчный JSON (JSONL) обрабатывается
  построчно и отклоняется целиком при ошибке любой строки.
- XML: DOCTYPE/DTD и неизвестные сущности отклоняются; комментарии и processing
  instructions очищаются необратимо и не восстанавливаются; CDATA с персональными данными
  становится обычным текстом. Имена элементов и атрибутов, а также объявления namespace
  не заменяются метками.
- Детекторы могут пропускать персональные данные (false negatives) и находить лишнее
  (false positives); проверка утечек (LeakGuard) снижает риск, но не устраняет его.
- Компрометация операционной системы, браузера, профиля или других расширений не
  покрывается моделью угроз.
- После перехвата служебная запись о загрузке живёт 2 минуты. Неизвестные двоичные
  запросы, не похожие на передачу файлов ChatGPT (другой сайт, путь или размер), не
  блокируются; это снижает число ложных блокировок, но не доказывает, что такой запрос не
  содержал исходные байты.
- Скрипт самой страницы chatgpt.com работает в том же источнике и технически может
  запустить восстановление по известному коду хранилища или метке (restore-oracle). Это не
  защита от скомпрометированной страницы. Подробнее — `SECURITY.md` §3.

## 8. Контакты

Поддержка и контакт для вопросов о приватности: контакт, опубликованный в карточке
расширения Chrome Web Store / Microsoft Edge Add-ons (support URL или email), а также
раздел Issues публичного репозитория проекта. Для сообщений об уязвимостях используйте
тот же канал; не прикладывайте реальные персональные данные.

## 9. Изменения

Политика может обновляться вместе с расширением. Существенные изменения отражаются в
`README.md`, в этой политике и в описании версии в магазине. Дата и версия указаны в
начале документа.
