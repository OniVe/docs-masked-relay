Черновик для отправки в магазин. Тот же пакет MV3, что и для Chrome:
`.output/docs-masked-relay-0.2.0-chrome.zip` (Edge принимает Chromium MV3 zip, отдельная
сборка для Edge не нужна). Не публиковать, пока не устранены внешние блокеры из
`SUBMISSION.md`.

юридическая консультация. Сохраните примечание о своих правилах: задаётся только метка
(`Иванов Иван => CLIENT` → `[[XXXXX_CLIENT_1]]`), а не произвольный текст замены, чтобы
восстановление оставалось точным.

## Формулировка о приватности для Edge

Используйте этот текст в описании или примечаниях Edge (в размещённой политике есть тот же
абзац в §6):

> Настоящая политика применяется к DocsMasked Relay, распространяемому через Microsoft Edge
> Add-ons. Расширение получает доступ к данным только в объёме, необходимом для явно
> заявленной пользователю функции — локальной замены персональных данных в файлах для
> ChatGPT метками и восстановления при скачивании, — и обрабатывает эти данные локально в
> браузере. Разработчик не собирает, не продаёт и не передаёт данные третьим лицам.
> Аналитики, рекламы и удалённой конфигурации нет. Поскольку данные не передаются
> разработчику или третьим лицам, отдельное согласие на такую передачу не требуется;
> установка расширения и явное включение перехвата — действия пользователя. Пользователь
> может отключить перехват, очистить все локальные данные или удалить расширение в любой
> момент. Та же политика распространяется на Edge-версию того же пакета.

Примечания для проверяющего и владельца:

- Политика Edge требует, чтобы политика конфиденциальности упоминала Edge Add-ons, а не
  только Chrome. На размещённой странице есть отдельный раздел Edge; заявление Chrome
  Limited Use сохранено как дополнительное обязательство.
- **Особо чувствительные данные:** расширение не нацелено на данные о здоровье или
  финансах, не собирает их и не передаёт разработчику. Пользователь может выбрать
  произвольные файлы с такими данными; эти байты обрабатываются локально, и в ChatGPT
  отправляется только обезличенная копия по действию пользователя. Отдельное согласие на
  сбор данных разработчиком не нужно, потому что такой сборки нет. Не добавляйте функции,
  которые проверяют или передают такие данные, без нового ревью.
- Разрешения: `storage`, `unlimitedStorage`, `offscreen`, доступ к `chatgpt.com`,
  `chat.openai.com`, `*.oaiusercontent.com` и два скрипта на страницах. Обоснования те же,
  что для Chrome (`store/chrome-listing.md`); нет `tabs`, `downloads`, `debugger`,
  `scripting`, `cookies`, `history`, `<all_urls>`.
- Удалённый код: **нет.** WebAssembly входит в пакет и собирается из Rust-крейтов
  репозитория; CDN, удалённой конфигурации, `eval` и динамической загрузки скриптов нет.
  Код минифицирован, но не обфусцирован; исходники и инструкции по сборке доступны.
- Использование данных: персональные данные, содержимое сайта и действия пользователя
  обрабатываются локально; разработчик не собирает, не продаёт и не передаёт их.
  Единственная внешняя передача — инициированная пользователем загрузка обезличенного файла
  в ChatGPT/OpenAI.

## Сертификация и сроки

- Сертификация в Microsoft Edge Add-ons может занимать **до 7 рабочих дней** (дольше, если
  карточка заполнена неполно или проверяющий запросил правки). Планируйте недели, а не часы.
- Обычные причины отказа — неполные поля карточки, несоответствие политике
  конфиденциальности, слабое обоснование разрешений или признаки malware/PUA. Пакет должен
  быть чистым, воспроизводимым и без удалённого кода.
- В Edge другой ID расширения, чем в Chrome; здесь нет OAuth и native messaging, поэтому
  список исключений по ID не нужен.

## Инструкция для проверяющих Edge

Ручной путь не требует ChatGPT:

1. Установите расширение, откройте его окно на панели браузера.
2. **Ручной режим** → выберите синтетический `.txt` с именем/телефоном/email → нажмите
   **Анонимизировать и скачать**. В результате будут метки вида `[[AB12C_PERSON_1]]`,
   исходных значений не будет.
3. **Ручной режим** → выберите обезличенный файл → **Восстановить и скачать**. Результат
   совпадёт с исходным.
4. Необязательно: повторите с синтетическими MD/JSON/XML/DOCX/XLSX. PDF обрабатывается в
   одну сторону по замыслу.
5. Для автоматического перехвата нужна открытая сессия <https://chatgpt.com/> с входом; без
   аккаунта ручной режим — полный локальный путь проверки.

Полные шаги проверки, проверки блокировки и безопасного отказа, а также известные
ограничения: `store/review-notes.md`.
