# Chrome Web Store — описание DocsMasked Relay 0.2.1

Черновик для отправки в магазин. Не публиковать, пока не устранены внешние блокеры из
`SUBMISSION.md`. Значения в `<угловых скобках>` — заполняет владелец проекта.

## Одна цель расширения

Локально обезличивать персональные данные в файлах перед отправкой в ChatGPT и
восстанавливать исходные значения при скачивании этого файла.

Это одна цель: замена данных метками при загрузке и восстановление при скачивании — два
направления одного локального процесса работы с файлом. Ручной режим (обработка файла,
выбранного в окне расширения) использует те же детекторы, хранилище и обработчики форматов
и служит запасным вариантом, если автоматический перехват недоступен.

### Полное описание (черновик)

> DocsMasked Relay — локальная защита файлов, которые вы отправляете в ChatGPT.
>
> Когда вы загружаете поддерживаемый файл в ChatGPT, расширение перехватывает его в
> браузере, находит персональные данные (имена, телефоны, email, адреса, номера
> документов и другие включённые категории), заменяет каждое значение меткой вида
> `[[DM7F3_PERSON_1]]` и отправляет только обезличенную копию. Соответствие между метками
> и исходными значениями хранится в зашифрованном хранилище на вашем устройстве. Когда вы
> скачиваете файл с метками, расширение возвращает исходные байты и имя файла.
>
> **Что остаётся локально:** исходные значения персональных данных, соответствия меток,
> ключи шифрования и настройки. **Что уходит в ChatGPT:** обезличенный файл, его
> обезличенное имя и обычные метаданные загрузки. У расширения нет сервера, аккаунта,
> телеметрии, аналитики и рекламы.
>
> Расширение работает с документами Word и Excel (включая старые версии), текстовыми и
> Markdown-файлами, JSON/JSONL, XML и PDF. Старые документы Word/Excel конвертируются в
> современные форматы; сложная вёрстка при этом может потеряться.
>
> В окне расширения есть ручной режим: он обезличивает или восстанавливает выбранный файл
> без ChatGPT и помогает, если сайт изменился.
>
> **Свои правила:** можно добавить точные термины, например `Иванов Иван => CLIENT`, и
> выбрать метку для них (например, `[[DM7F3_CLIENT_1]]`). Строка без `=>` использует метку
> по умолчанию. Правило задаёт только метку, а не произвольный текст замены, чтобы файл
> можно было точно восстановить из зашифрованного хранилища.
>
> **Ограничения:** необратимое удаление в PDF нельзя отменить, восстановить такой PDF
> нельзя. Сканы PDF без текстового слоя блокируются (распознавания текста нет). Изображения,
> встроенные объекты и вложения внутри документов не проверяются. Автоматические проверки
> могут пропустить данные или заменить лишнее; проверка утечек снижает, но не устраняет этот
> риск. Структуры JSON/XML, которые нельзя безопасно обезличить, отклоняются целиком. Старые
> форматы DOC/XLS конвертируются с потерей вёрстки. Расширение не защищает от OpenAI:
> загруженный обезличенный файл хранится у OpenAI по их правилам. Это не юридическая
> консультация и не гарантия соблюдения законов о персональных данных.
>
> Политика конфиденциальности: `<HOSTING URL>`

**История проверки.** Первая отправка (2026-11-23) была отклонена с нарушением
«Yellow Argon» («Избыточные ключевые слова в описании продукта»): причиной был длинный
список форматов в описании. Текущая формулировка перечисляет форматы прозой — не
возвращайте список аббревиатур и не добавляйте перечисление ключевых слов.

## Обоснование разрешений

Эти формулировки — для полей «Privacy practices» в Chrome Web Store.

| Разрешение / доступ | Зачем нужно |
| --- | --- |
| `storage` | Хранит настройки расширения (включение перехвата, категории персональных данных, лимит размера, автоблокировку, свои термины и список исключений) и небольшие служебные флаги локально. Удалённой синхронизации нет. |
| `unlimitedStorage` | Зашифрованное хранилище находится в IndexedDB расширения. У пользователя может накопиться много соответствий из разных чатов, а стандартной квоты расширения не хватает. Данные остаются на устройстве. |
| `offscreen` | Используется только во время обработки PDF: служебная страница запускает локальный модуль обработки PDF (WebAssembly) и рабочий поток. У неё нет интерфейса, она не делает сетевых запросов и создаётся только при необходимости. |
| Доступ к `https://chatgpt.com/*` | Скрипты расширения должны работать на странице ChatGPT, чтобы перехватить загрузку и скачивание файла пользователя и подменить байты обезличенной или восстановленной версией. Другие сайты расширение не читает. |
| Доступ к `https://chat.openai.com/*` | Старый адрес ChatGPT; тот же перехват загрузки и скачивания для пользователей, которые ещё пользуются этим доменом. |
| Доступ к `https://*.oaiusercontent.com/*` | Загрузка и скачивание в ChatGPT идут через подписанные ссылки на этом транспортном домене OpenAI/Azure. Расширению нужно отправлять обезличенные байты и получать файлы с метками по этим адресам. Расширение не просматривает и не собирает содержимое этого домена. |
| Скрипты на страницах (MAIN + ISOLATED) | Два скрипта подключаются в начале загрузки страницы и только на указанных выше доменах. Скрипт MAIN перехватывает `fetch`/XHR и получает выбранный пользователем `File`; скрипт ISOLATED передаёт проверенные сообщения фоновой части расширения и показывает уведомление на странице. API расширения странице не доступен, удалённый код не загружается. |

Других разрешений нет. Пакет **не** использует `tabs`, `downloads`, `debugger`, `scripting`,
`cookies`, `history` или `<all_urls>`. Разрешение `downloads` намеренно не запрашивается:
результат ручного режима сохраняется через ссылку на blob.

## Заявление об удалённом коде

**Ответ: нет — расширение не использует удалённый код.**

- Два модуля WebAssembly (`pii-scan.wasm`, `codec.wasm`) входят в пакет. Они собраны из
  Rust-крейтов в публичном репозитории командой `bun run build:wasm`; CDN, удалённая
  конфигурация, динамический импорт и `eval` не используются.
- CSP в manifest: `script-src 'self' 'wasm-unsafe-eval'; object-src 'self'; worker-src 'self'`.
  `wasm-unsafe-eval` нужен только для запуска локального WebAssembly; он не разрешает
  удалённые скрипты или JavaScript `eval`.
- Пакет минифицирован стандартной production-сборкой WXT/Vite, но не обфусцирован. Исходный
  код и инструкции по сборке доступны по запросу и в публичном репозитории.

## Раскрытие использования данных (вкладка Privacy practices)

Отвечайте консервативно. Расширение обрабатывает данные локально; разработчик ничего не
получает.

| Категория Chrome | Выбрано | Пояснение |
| --- | --- | --- |
| Personally identifiable information (персональные данные) | **Да** | Содержимое файлов может включать имена, email, телефоны, адреса, номера документов. Обрабатывается локально для создания обезличенной копии; исходные значения остаются в зашифрованном хранилище на устройстве. |
| Health information (здоровье) | Нет (не намеренно) | Расширение не нацелено на данные о здоровье. В произвольных файлах они могут встретиться; обработка локальная, разработчик их не собирает. |
| Financial and payment information (финансы и платежи) | Нет (не намеренно) | То же рассуждение; числовые значения, похожие на персональные данные, в JSON отклоняются. Платёжные данные не собираются. |
| Authentication information (аутентификация) | Нет | Расширение не читает учётные данные, cookies или токены ChatGPT. |
| Personal communications (личная переписка) | Нет | Оно не читает сообщения чата или почту; обрабатываются только файлы, которые пользователь загружает и скачивает. |
| Location (местоположение) | Нет | API геолокации не используется, IP не собирается. |
| Web history (история браузера) | Нет | Работает только на доменах ChatGPT/OpenAI и не записывает историю просмотров. |
| User activity (действия пользователя) | **Да** | Загрузка и скачивание на ChatGPT наблюдаются локально, чтобы запустить обезличивание или восстановление. Разработчику не передаются. |
| Website content (содержимое сайта) | **Да** | Скрипт на chatgpt.com видит запросы на передачу файлов и байты, которые загружает пользователь; это нужно, чтобы заменить данные метками. Разработчику не передаются. |

Подтверждения:

- Данные **не продаются** третьим лицам.
- Данные **не передаются** третьим лицам, не связанным с единственной целью. Единственная
  внешняя передача — инициированная пользователем загрузка обезличенного файла в
  ChatGPT/OpenAI; обращение OpenAI с ним регулируется политикой OpenAI.
- Данные **не используются и не передаются** для целей, не связанных с единственной целью,
  для оценки кредитоспособности или кредитования.
- Данные **не собираются разработчиком**: нет аналитики, телеметрии, удалённого
  логирования и рекламы.
- Заявление Limited Use включено дословно в политику конфиденциальности и применяется ко
  всем пользовательским данным, которые обрабатывает расширение.

## Инструкция для проверяющих

Вставьте в поле «Test instructions» (кратко; полные шаги — в `store/review-notes.md`).

1. Установите расширение и откройте его окно на панели браузера. Для ручного режима аккаунт
   не нужен.
2. В разделе **Ручной режим** выберите синтетический файл `.txt` с именем, телефоном и
   email, нажмите **Анонимизировать и скачать**. В скачанном файле будут метки вида
   `[[XXXXX_PERSON_1]]`, исходных значений не будет.
3. Выберите этот обезличенный файл в разделе **Восстановить файл** и нажмите
   **Восстановить и скачать**. Скачанный файл совпадёт с исходным текстом.
4. Повторите с синтетическими `.md`, `.json`, `.xml`, `.docx`, `.xlsx`. PDF обрабатывается
   в одну сторону: обезличенный PDF по замыслу не восстанавливается.
5. Необязательный автоматический путь: войдите на <https://chatgpt.com/> под аккаунтом
   проверяющего, убедитесь, что включён **Перехватывать файлы в ChatGPT**, загрузите
   синтетический поддерживаемый файл, затем скачайте его из чата и проверьте восстановление.
   Без аккаунта ChatGPT доступен только ручной путь: автоматический перехват требует
   открытого веб-приложения с входом.

Тестовые учётные данные не предоставляются. Не используйте в тестовых файлах реальные
персональные данные.
