DocsMasked Relay — Политика конфиденциальности

Дата вступления в силу: 23 ноября 2026 · Версия расширения: 0.2.1

DocsMasked Relay — расширение браузера для Chrome и Microsoft Edge (а также для Safari, если оно будет распространяться отдельно). Оно локально находит персональные данные (PII) в файлах, заменяет их метками перед отправкой файла в ChatGPT и восстанавливает исходные значения при скачивании. У расширения нет сервера, аккаунта, телеметрии, аналитики, рекламы и внешних API. Разработчик не собирает и не получает пользовательские данные.

1. Какие данные обрабатывает расширение

  • Содержимое, имена и метаданные файлов, которые вы выбираете или перетаскиваете.
  • Настройки расширения: включение перехвата, категории персональных данных, лимиты, списки терминов.
  • Хранилище (vault): зашифрованное соответствие меток и исходных значений, а также исходные имена файлов.
  • Служебные идентификаторы: код хранилища (5 символов), id чата ChatGPT, время операций.

Обработка идёт в вашем браузере. Скрипт на странице ChatGPT только перехватывает файлы и передаёт их байты; поиск данных и работа с форматами (TXT/MD/DOCX/XLSX/ JSON/JSONL/XML/DOC/XLS) выполняются в фоновой части расширения. PDF обрабатывается там же (в Chrome/Edge — с помощью отдельной служебной страницы браузера). Отдельного сервера нет.

Минимум данных Расширение обрабатывает только те файлы, которые вы сами отправляете или выбираете вручную, и только в объёме, необходимом для локальной замены метками или восстановления. Оно не читает другие сайты, не строит профили, не собирает историю просмотров и не использует данные для рекламы, аналитики или оценки кредитоспособности. Содержимое файлов не передаётся разработчику и не попадает на сторонние серверы, кроме описанной ниже обезличенной копии, которую вы отправляете в ChatGPT.

2. Что покидает ваше устройство

Только то, что вы сами отправляете в ChatGPT:

  • Обезличенные файлы, отправленные на chatgpt.com и на подписанные ссылки *.oaiusercontent.com (инфраструктура OpenAI/Azure).
  • Обезличенное имя файла и метаданные загрузки (размер, тип файла).
  • Запросы к chatgpt.com, которые делает сам веб-клиент ChatGPT.
  • При скачивании — запросы к тем же доменам ChatGPT/OpenAI.

Хранилище, ключи шифрования, настройки и исходные значения персональных данных никогда не покидают ваше устройство. В ChatGPT отправляется только обезличенная копия; исходные значения остаются локально. Расширение не продаёт данные, не передаёт их третьим лицам для их собственных целей и не использует для рекламы.

Важно: после загрузки обезличенный файл хранится у OpenAI по политике OpenAI. Расширение не защищает от самого ChatGPT и не отменяет правила сервиса.

3. Хранение, сроки и удаление

  • Хранилище и ключи находятся в локальной базе браузера (IndexedDB расширения, dmrelay), а не в облаке.
  • Содержимое хранилища шифруется алгоритмом AES-GCM-256. Ключ устройства хранится как неэкспортируемый CryptoKey; дополнительная парольная фраза защищает основной ключ через PBKDF2-SHA256 (600 000 итераций, соль 16 байт).
  • Служебные метаданные хранилища (код хранилища, id чатов, время операций, IV/шифротекст) не содержат персональных данных; имена файлов и значения сущностей находятся только внутри шифротекста.
  • Исключение: списки «Свои термины» (customTerms) и «Список исключений» (allowlist) в настройках хранятся в открытом виде и не входят в шифрованное хранилище. Если вы вводите там реальные имена или термины, они видны в локальной базе расширения без парольной фразы. Шифрование этих списков пока не реализовано.
  • Сроки хранения: хранилище хранится до удаления пользователем; служебная запись о загрузке живёт 2 минуты после перехвата; автоблокировка (по умолчанию 15 минут бездействия) очищает ключ из памяти. Серверного хранения нет.
  • Экспорт создаёт только зашифрованный JSON, защищённый отдельной парольной фразой; импорт отклоняет дубликаты id и кодов хранилища.
  • Удаление: «Настройки → Очистка данных» удаляет хранилище, ключи и настройки без возможности восстановления. Удаление расширения из браузера также удаляет его локальные данные. Запрашивать удаление у разработчика не нужно, потому что разработчик никогда не получает данные.

4. Разрешения и зачем они нужны

Разрешение Назначение
storage Настройки и служебные флаги.
unlimitedStorage Хранилище в IndexedDB.
offscreen (Chrome/Edge) Служебная страница для обработки PDF; используется только при работе с PDF.
Доступ к https://chatgpt.com/*, https://chat.openai.com/* Перехват загрузки и скачивания на страницах ChatGPT.
Доступ к https://*.oaiusercontent.com/* Передача и получение байтов по подписанным ссылкам.
Скрипты на страницах Только на chatgpt.com, для перехвата файлов и связи со страницей.

Расширение не запрашивает tabs, downloads, debugger или <all_urls> и не содержит удалённого кода.

5. Chrome Web Store / Google API Limited Use

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Расширение не использует Google API и не получает данные от Google. Тем не менее любая обработка пользовательских данных ограничена заявленной единственной целью: локальная замена персональных данных в файлах для ChatGPT метками и восстановление при скачивании. Данные не используются и не передаются для рекламы, аналитики, профилирования, оценки кредитоспособности или иных задач, не связанных с этой единственной целью.

6. Microsoft Edge Add-ons

Настоящая политика применяется к расширению, распространяемому через Microsoft Edge Add-ons. Расширение получает доступ к данным только в объёме, необходимом для явно заявленной пользователю функции (локальная замена данных в файлах метками и восстановление), и обрабатывает эти данные локально. Разработчик не собирает, не продаёт и не передаёт данные третьим лицам; аналитики, рекламы и удалённой конфигурации нет. Поскольку данные не передаются разработчику или третьим лицам, отдельное согласие на такую передачу не требуется; установка расширения и явное включение перехвата — действия пользователя. Вы можете отключить перехват, очистить данные или удалить расширение в любой момент. Требования Edge Add-ons к раскрытию и минимизации данных соблюдаются; та же политика распространяется на Edge-версию того же пакета.

7. Ограничения

  • Расширение не является юридической консультацией и не гарантирует соответствие GDPR, 152-ФЗ России или иным требованиям.
  • PDF после необратимого удаления (redaction) не восстанавливается.
  • Сканы PDF без текстового слоя блокируются; распознавание текста (OCR) не входит в эту версию.
  • Изображения, встроенные объекты, диаграммы и вложения внутри документов не проверяются.
  • Старые форматы (legacy) .doc/.xls конвертируются в .docx/.xlsx с потерей вёрстки.
  • JSON: числовые значения с признаками персональных данных (ИНН/СНИЛС/ОГРН/карта/ счёт/телефон) отклоняются, а не заменяются метками; построчный JSON (JSONL) обрабатывается построчно, и весь файл отклоняется, если хотя бы одна строка не прошла проверку.
  • XML: DOCTYPE/DTD и неизвестные сущности отклоняются; комментарии и processing instructions удаляются необратимо; CDATA с персональными данными становится обычным текстом. Имена элементов и атрибутов, а также объявления namespace не заменяются метками.
  • Детекторы вероятностные: возможны пропуски (false negatives) и лишние замены (false positives); проверка утечек (LeakGuard) снижает риск, но не устраняет его.
  • Компрометация операционной системы, браузера, профиля или других расширений не покрывается моделью угроз.
  • После перехвата служебная запись о загрузке живёт 2 минуты. Неизвестные двоичные запросы, не похожие на передачу файлов ChatGPT (другой сайт, путь или размер), не блокируются; это снижает число ложных блокировок, но не доказывает, что такой запрос не содержал исходные байты.
  • Скрипт страницы chatgpt.com работает в том же источнике и технически может запустить восстановление по известному коду хранилища или метке (restore-oracle). Это не защита от скомпрометированной страницы. Подробнее — SECURITY.md §3 в репозитории проекта.

8. Контакты

Вопросы о приватности и поддержка: контакт, опубликованный в карточке DocsMasked Relay в Chrome Web Store или Microsoft Edge Add-ons (support URL или email), либо раздел Issues публичного репозитория проекта. Для сообщений об уязвимостях используйте тот же канал и не прикладывайте реальные персональные данные.

Та же политика на русском языке поддерживается в репозитории проекта как extension/PRIVACY.md.

9. Изменения

Политика может обновляться вместе с расширением. Существенные изменения отражаются в README репозитория, в этой политике и в описании версии в магазине. Дата вступления в силу и версия расширения указаны в начале этой страницы.
