# DocsMasked Relay — установщик для Windows

Установщик распакованного расширения **DocsMasked Relay** для Chrome и Edge, для одного
пользователя. Без прав администратора, без сети, без публикации в магазинах и без обхода
политик браузера. Установщик не подписан; это локальная сборка, её не следует публиковать
как официальный релиз.

## Что делает установщик

1. Распаковывает текущую сборку расширения в
   `%LOCALAPPDATA%\DocsMaskedRelay\extension` (только для текущего пользователя).
2. Проверяет `manifest.json`: `manifest_version = 3`, непустые `name` и `version`, наличие
   файлов, на которые ссылается manifest.
3. Заменяет предыдущую версию целиком: сначала распаковывает в `extension.new`, проверяет,
   затем переименовывает старую папку в `extension.old-<timestamp>` и подставляет новую. При
   ошибке старая версия возвращается на место.
4. Записывает `install.json`: `version`, `installedAt` (UTC), `source`, `payloadSha256`,
   пути, браузер.
5. Копирует `uninstall.ps1`, `uninstall.cmd` и `INSTALL-INSTRUCTIONS.txt` в папку установки.
6. Создаёт ярлыки в меню Пуск (только текущий пользователь):
   - «Открыть папку расширения»;
   - «Открыть страницы расширений Edge/Chrome»;
   - «Удалить DocsMasked Relay».
7. Открывает проводник с папкой расширения и страницу `edge://extensions/` или
   `chrome://extensions/`, затем показывает окно с оставшимися ручными шагами.

## Чего установщик НЕ делает

- **Не устанавливает расширение молча.** Chrome и Edge на Windows не разрешают тихую
  установку распакованных расширений не из магазина. Установщик не обходит это ограничение
  и не выдаёт себя за магазин.
- Не использует `--load-extension`, не включает режим разработчика за пользователя и не
  добавляет расширение в профиль.
- Не пишет в `HKLM`, не создаёт политики `ExtensionInstallForcelist`,
  `ExtensionSettings`, `ExtensionInstallAllowlist` и т. п.
- Не запрашивает права администратора и не делает UAC-повышение.
- Не трогает профиль браузера, базу расширения, хранилище, cookies, закладки и документы.
- Не скачивает ничего из сети и не отправляет телеметрию.
- Не устанавливает расширение Safari (Safari не входит; см. ниже).
- Не удаляет хранилище. Оно находится в профиле браузера, а не в папке установки.

## Требования

- Windows 10 или Windows 11 (x64).
- Windows PowerShell 5.1 (`powershell.exe`) — входит в Windows.
- Microsoft Edge и/или Google Chrome (stable).
- Свободное место: около 40 МБ на установку и временную распаковку.
- Права обычного пользователя. Администратор не нужен.

Поддерживаются пути с пробелами и кириллицей (имя пользователя, `%LOCALAPPDATA%`, папка
установки).

## Установка из exe

1. Скачайте или скопируйте `DocsMaskedRelay-Setup-<version>.exe` **из доверенного
   источника**. Файл не подписан.
2. Запустите exe двойным щелчком.
3. Windows SmartScreen может показать «Windows protected your PC». Это ожидаемо для
   неподписанного exe. Если вы доверяете файлу и проверили SHA256, нажмите «More info» →
   «Run anyway». Если не доверяете — не запускайте.
4. Установщик распакует файлы, создаст ярлыки и откроет браузер с папкой.
5. Выполните последний шаг вручную (браузер не позволяет иначе):
   1. На странице `edge://extensions/` (или `chrome://extensions/`) включите
      **Режим разработчика** (Developer mode).
   2. Нажмите **Загрузить распакованное расширение** (Load unpacked).
   3. Выберите папку:
      `%LOCALAPPDATA%\DocsMaskedRelay\extension`
      (установщик уже открыл её в проводнике; путь можно вставить в адресную строку).
   4. Убедитесь, что расширение включено, и закрепите иконку DocsMasked Relay на панели
      браузера.
6. Откройте <https://chatgpt.com/> и проверьте, что иконка расширения активна.

Точная инструкция также лежит в
`%LOCALAPPDATA%\DocsMaskedRelay\INSTALL-INSTRUCTIONS.txt`.

## Установка из переносимого zip

Если exe не собрался или политика запрещает запуск exe:

1. Распакуйте `DocsMaskedRelay-Portable-<version>.zip` **целиком** в любую папку.
2. Запустите `install.cmd` (или `powershell.exe -NoProfile -ExecutionPolicy Bypass
   -File install.ps1`).
3. Дальше — те же шаги «Загрузить распакованное расширение», что выше.

Переносимый zip содержит те же `install.ps1`, `uninstall.ps1`, `payload.zip` и инструкцию.
Сеть не нужна.

## Обновление

1. Закройте вкладки ChatGPT (не обязательно, но надёжнее).
2. Запустите новый `DocsMaskedRelay-Setup-<version>.exe` или новый переносимый zip.
   Установщик заменит папку `extension`, а предыдущую версию сохранит в
   `extension.old-<timestamp>`.
3. На странице расширений нажмите **Обновить** (Reload) у DocsMasked Relay. Папка та же,
   поэтому расширение подхватит новые файлы.
4. Хранилище и настройки расширения остаются в профиле браузера.

Старые резервные папки `extension.old-*` удаляются при следующей установке; хранится только
последняя.

## Удаление

1. Сначала удалите расширение в браузере:
   `edge://extensions/` или `chrome://extensions/` → **Удалить** (Remove). Это также удалит
   данные расширения и хранилище по правилам браузера.
2. Затем запустите ярлык **«Удалить DocsMasked Relay»** в меню Пуск или `uninstall.cmd` /
   `uninstall.ps1` из папки установки. Скрипт удалит `%LOCALAPPDATA%\DocsMaskedRelay` и
   ярлыки.
3. Хранилище в профиле браузера этим скриптом не удаляется. Если расширение уже удалено,
   его данные удаляет сам браузер.

`uninstall.ps1` понимает `-InstallRoot <path>` (для тестов) и `-NoShortcuts`. При
интерактивном запуске он спрашивает подтверждение; для автоматизации есть `-Force`.

Если браузер держит файлы расширения открытыми и удаление не удалось, закройте браузер (или
удалите расширение на странице расширений) и повторите.

## Ограничения

- **Политика Chrome/Edge для расширений не из магазина.** Браузеры требуют режим
  разработчика и ручную загрузку распакованного расширения. Это не ошибка установщика;
  установщик сознательно не обходит политику. Корпоративные политики
  (`DeveloperToolsAvailability`, `ExtensionDeveloperModeSettings` и аналоги) могут вообще
  запретить такую загрузку — установщик это не меняет.
- **Неподписанный exe.** IExpress exe не подписан. SmartScreen и антивирусы могут
  предупредить или заблокировать запуск. Подпись EV/OV сертификатом не входит в эту сборку.
- **Нет автообновления.** Обновление — повторный запуск нового установщика и **Обновить** в
  браузере. Магазин и автообновление не используются.
- **Chrome показывает предупреждение** про расширение в режиме разработчика при запуске.
  Это поведение браузера для распакованных расширений.
- **Safari не входит.** Safari Web Extension собирается и подписывается отдельно на macOS
  (см. `extension/docs/safari-build.md`); этот установщик только для Windows/Chrome/Edge.
- **Хранилище в профиле браузера.** Установщик не имеет доступа к профилю и не удаляет
  хранилище; удаление расширения в браузере — отдельный шаг.
- **IExpress не передаёт аргументы** запущенному `install.cmd`. Для автоматического теста
  exe предусмотрены переменные окружения `DMRELAY_INSTALL_ROOT`, `DMRELAY_NO_OPEN=1`,
  `DMRELAY_NO_SHORTCUTS=1`, `DMRELAY_BROWSER=None` (см. ниже). Обычному пользователю они не
  нужны.
- **Ничего не публикуйте.** Это локальная неподписанная сборка; публикация в магазинах и
  массовое распространение не входят в задачу.

## Приватность и безопасность

- Установщик работает офлайн: не делает HTTP-запросов, не скачивает обновления, не
  отправляет телеметрию.
- Он пишет только:
  - `%LOCALAPPDATA%\DocsMaskedRelay\` (файлы расширения, `install.json`, `uninstall.*`,
    инструкция, резервная копия);
  - ярлыки в `%APPDATA%\Microsoft\Windows\Start Menu\Programs\DocsMasked Relay\`.
- Он не пишет в реестр (кроме чтения `App Paths` для поиска браузера), не пишет в `HKLM`, не
  меняет политики и не трогает профиль браузера.
- SHA256 артефактов — в `SHA256SUMS`. Проверка в PowerShell:
  `Get-FileHash .\DocsMaskedRelay-Setup-<version>.exe -Algorithm SHA256`.
- Скрипты используют только встроенные средства Windows: `Expand-Archive`, `WScript.Shell`
  для ярлыков, `System.IO.Compression` для zip.

## Сборка

Требования для сборки: Bun 1.4+, зависимости расширения (`bun install` в `extension/`).
Сеть нужна только для `bun install`; сам установщик сеть не использует.

```powershell
cd installer
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build-installer.ps1
```

Скрипт:

1. Проверяет `extension\.output\chrome-mv3\manifest.json`; если сборки нет или исходники
   новее — выполняет `bun run build` в `extension` (если `bun` и `node_modules` доступны).
2. Читает version из manifest.
3. Создаёт `installer\staging\payload.zip` (содержимое расширения в корне zip).
4. Собирает `installer\dist\DocsMaskedRelay-Setup-<version>.exe` через
   `C:\Windows\System32\iexpress.exe /N /Q` и сгенерированный SED.
5. Собирает `installer\dist\DocsMaskedRelay-Portable-<version>.zip`.
6. Копирует `payload.zip` в `dist`, пишет `SHA256SUMS`.

Параметры: `-SkipBuild` (использовать готовую сборку), `-SkipExe` (только переносимый zip),
`-Rebuild` (принудительно `bun run build`), `-OutputDir <path>`.

Если IExpress недоступен или завершился ошибкой, сборка не притворяется успешной:
переносимый zip всё равно создаётся, в консоли и в `dist\BUILD-FALLBACK.txt` указывается
причина, exe отсутствует.

### Структура

```
installer/
  src/
    install.ps1              # установка (PS 5.1)
    uninstall.ps1            # удаление
    install.cmd              # обёртка powershell.exe
    uninstall.cmd
    INSTALL-INSTRUCTIONS.txt # шаблон инструкции
  build-installer.ps1        # payload + переносимый zip + IExpress exe
  tests/
    smoke.ps1                # установка/обновление/удаление во временном root
  dist/                      # артефакты сборки (gitignore)
  staging/                   # payload.zip, SED, package (gitignore)
  README.md
```

## Проверка

Smoke-тест не трогает реальный `%LOCALAPPDATA%\DocsMaskedRelay`, не создаёт ярлыки, не
открывает браузер и не использует сеть:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File installer\tests\smoke.ps1
```

Он устанавливает во временный путь с пробелами и кириллицей, проверяет
manifest/install.json/файлы, делает повторную установку (резервная копия), запускает
uninstall и проверяет полное удаление.

Проверка exe (IExpress не передаёт аргументы, поэтому используются переменные окружения; это
только для теста, не для обычной установки):

```powershell
$env:DMRELAY_INSTALL_ROOT = Join-Path $env:TEMP 'dmrelay-exe-test'
$env:DMRELAY_NO_OPEN = '1'
$env:DMRELAY_NO_SHORTCUTS = '1'
$env:DMRELAY_BROWSER = 'None'
Start-Process .\installer\dist\DocsMaskedRelay-Setup-0.2.0.exe -Wait
Get-Content (Join-Path $env:DMRELAY_INSTALL_ROOT 'install.json')
powershell.exe -NoProfile -ExecutionPolicy Bypass -File (Join-Path $env:DMRELAY_INSTALL_ROOT 'uninstall.ps1') -InstallRoot $env:DMRELAY_INSTALL_ROOT -NoShortcuts -Force
```

## Если что-то пошло не так

| Симптом | Что делать |
| --- | --- |
| SmartScreen блокирует exe | Проверьте SHA256; если доверяете — More info → Run anyway. Или используйте переносимый zip. |
| `running scripts is disabled` | Запускайте `install.cmd` / `uninstall.cmd`: они используют `-ExecutionPolicy Bypass` только для своего процесса. |
| «Загрузить распакованное расширение» недоступно | Включите режим разработчика. Если политика организации запрещает — обратитесь к администратору; установщик политику не обходит. |
| Браузер не найден | Установка продолжится; откройте `edge://extensions/` или `chrome://extensions/` вручную. |
| Не удаляется папка | Закройте браузер, удалите расширение на странице расширений, повторите удаление. |
| Антивирус ругается на IExpress | Это типичный эвристический флаг для самораспаковывающегося exe. Используйте переносимый zip или соберите exe самостоятельно из исходников. |
| Иконка расширения не видна | На странице расширений нажмите «Закрепить» (Pin). |

## Обратная связь и границы

Это установщик текущей сборки; интерфейс расширения он не меняет. Изменения интерфейса
делаются в отдельных ветках, после их объединения установщик пересобирается. Safari,
публикация в Chrome Web Store / Edge Add-ons, подпись кода и автообновление в эту задачу не
входят.
