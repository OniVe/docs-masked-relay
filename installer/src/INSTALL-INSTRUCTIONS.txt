DocsMasked Relay {{VERSION}} — инструкция по включению
============================================================

Chrome и Edge не разрешают автоматически включать расширения, установленные
не из магазина. Последний шаг выполняется вручную — это не ошибка установки.

1. Откройте страницу расширений:
   {{BROWSER_URL}}

2. Включите «Режим разработчика» (Developer mode).

3. Нажмите «Загрузить распакованное расширение» (Load unpacked).

4. Выберите папку:
   {{EXTENSION_PATH}}

5. Убедитесь, что DocsMasked Relay включён, и закрепите его иконку на панели.

Обновление
----------
Запустите новый установщик, затем нажмите «Обновить» (Reload) у расширения на
странице расширений. Папка расширения остаётся прежней, vault сохраняется.

Удаление
--------
1. Удалите расширение на странице {{BROWSER_URL}} кнопкой «Удалить» (Remove).
2. Запустите ярлык «Удалить DocsMasked Relay» в меню Пуск (или uninstall.cmd
   в папке установки).

Vault и данные расширения хранятся в профиле браузера. Этот установщик их не
удаляет и не изменяет профиль.

Безопасность
------------
* Установщик не подписан. SmartScreen может предупредить при запуске exe:
  запускайте файл только из источника, которому доверяете.
* Установщик не использует сеть, не пишет в HKLM и не меняет политики браузера.
* Права администратора не нужны.
